# Glossary

- **Agent** — the assistant that proposes tool calls; see [[Agent]].
- **Tool** — a registered action the agent may request (46 of them).
- **L1 to L4** — permission levels: read, draft, write (confirmed), never.
- **Care link** — an active doctor-to-patient access created by a one-time code.
- **Share link** — a time-limited QR or link for the doctor console.
- **SOAP** — Subjective, Objective, Assessment, Plan: the clinical note format.
- **DDInter** — drug-interaction dataset used for clash checks.
- **FHIR** — hospital record exchange format we can import.
- **Laya** — optional triage classifier, currently off ([[AI services]]).
- **Vault** — encrypted file store (AES-256-GCM).
- **In-flight cap** — limit on simultaneous API requests ([[Scalability]]).
